# 🏥 Healthcare Appointment System (CI/CD Project)

## 📌 Project Overview
This is a simple Healthcare Appointment System developed as part of a DevOps course project.  
The main focus of this project is to demonstrate **CI/CD pipeline implementation using GitHub Actions**.

The system allows basic appointment management using a Node.js backend.

---

## 🚀 Features

- Create healthcare appointments
- View all appointments
- Simple REST API using Express.js
- Automated CI/CD pipeline using GitHub Actions

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- Git & GitHub
- GitHub Actions (CI/CD)
